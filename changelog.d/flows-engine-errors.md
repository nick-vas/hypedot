Changed: the flows runner counts a flow as failed only from its own end line or an error of its own between its markers. The errors Godot's C# bindings log (`Handle is not initialized.`, godotengine/godot#124587) are warnings (`runnerResults[].warnings[]`, rule `engine-internal-error`, with the flow that was running) instead of failing flows that ended `ok`; the same for `validate`. The flows run with a throwaway `user://` folder on Linux and Windows, so a setting saved by an earlier run (a camera-sway toggle once turned `menu_navigation` red) does not reach them. The pull request comment's list of warnings is headed "Warnings", not "Architecture warnings". Fixes #231.
