Added: `status` and `plan` take `-TimeoutSec` (default 120 for `status` and a plain `plan`; none for `plan -Do sync|move|...`; 0 turns it off). git, a GitHub call and the folder walk are bounded by it: when it runs out the command still returns what it gathered, `partial` lists each skipped step and what it waited for (an editor holding git, a slow folder), and the text starts with PARTIAL. A GitHub call of `plan -Do sync` that outlives it stops with the new error code `command-timeout`, naming the call. The flag is refused on other commands. Fixes #230.
