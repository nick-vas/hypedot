Changed: `.claude-plugin/plugin.json` declares no `version`, so Claude Code takes every commit on `main` as a new version of the plugin and a game that enables it from GitHub gets each merged change (a pinned version would hold it until the string changed). `release.yml` no longer checks the manifest against the release version (the tag and the changelog section carry it); `doctor`'s issue report and the label's default read the newest changelog heading. `Test-WorkflowLint.ps1` fails if a version comes back.
