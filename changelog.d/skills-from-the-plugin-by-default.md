Changed: `init -Agents` no longer copies the skills and subagents into the game. It writes `AGENTS.md`, `CLAUDE.md` and `docs/kit-notes.md` and enables the hyperdot plugin in `.claude/settings.json`, which supplies the skills, the subagents and the hooks, so nothing in the game goes stale (`-Plugin` is now the same as `-Agents`). New `-CopySkills` copies them for a host that loads no plugins, and is refused in a game that already enables the plugin (each skill would load twice). New `-PluginSource github|local` (default `github`: this repository, `HYPERDOT_KIT_REPO` for a fork, works in cloud sessions, and every commit on `main` is a new plugin version; `local`: the kit's folder, loaded in place); a game that already has the plugin from the other source keeps it unless `-PluginSource` is given, and the old `settings.json` is kept as `.bak`. `init` no longer writes `docs/kit-help.md`, a copy that went stale (`help` and `/kit` write `.godot/kit-help.md`); it names an old copy so it can be deleted. The README, `docs/usage.md`, `docs/reference.md` and the help text say so.
