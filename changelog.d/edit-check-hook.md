Added: the plugin's edit hook (`hooks/edit-check.ps1`, `HYPERDOT_EDIT_CHECK=off` to disable). After Claude edits a `.gd`, `.tscn` or `.tres` file it loads that one file in headless Godot (`ci/godot/tools/editcheck.gd`) and tells Claude at once if the file has a syntax error, an undeclared name or a missing script or resource, instead of at the end of the turn. It costs the engine's start-up (about 0.2 s, measured the same on 6 and on 800 files), says nothing when the file loads, never blocks, and skips what it cannot check (no Godot, a game not yet imported, `addons/`, C#). `Test-EditCheck.ps1` covers it.
