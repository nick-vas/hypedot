Added: the `flows` runner resets the state autoloads hold between flows: every autoload with a `hyperdot_reset_flow_state()` method is called before the first flow and after each (it may return a String saying what it found dirty, shown in the flow's note), so a flow that asserts "the run holds 0 relics" passes alone and in a full run. The `ui-flows` skill documents the convention. Fixes #240.
