Changed: the Stop hook no longer blocks a session for code that already passed: each `test` run in the history is stamped with the git tree of the working folder (`tree`, tracked and untracked files, without touching the repository's index), and the hook lets the session finish when the tree in front of it is one that passed a full run, whatever the file times say (a checkout, a pull or a merge changes times, not the code). Other content is blocked as before.
